# Vesluma

以地标激活、区域揭雾和旅行记录为核心，支持个人探索与小队同行的城市探索记录应用。

> Uncover the city. Keep the memories.<br>
> 展开一座城，留下这一程。

当前阶段为产品与 MVP 设计，测试城市采用南京和西安。应用尚未实现，城市区划及拍照点仍需现场核实。

## 核心规则

- 地标由近及远展示，目标指南针提供方向，用户自主选择如何移动。
- 未解锁区域隐藏详细底图与路网，到访地标后展开按现实结构划分的区域。
- 实际足迹以定位点呈现，不连接成路线。
- 小队打卡只上传一次，云端保存默认不公开，公开分享由用户主动选择。
- 开图进度永久保留，重访不重置；首次激活与重访记录的具体方式见 MVP 设计建议。
- 持续定位的范围和生命周期后续专门设计。
