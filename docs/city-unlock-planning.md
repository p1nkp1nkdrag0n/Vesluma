# 南京 × 西安：全市分区与地标分级

版本：`citywide-2026-10-02`。本方案落实 2026-10-02 用户要求：完整覆盖南京市，并按同样原则规划西安；按地理组团和景点代表性分级；只有最高一级地标承担开图，密集景点不得为增加解锁条件而被切成小区块。

## 分级规则

| 级别 | 产品职责 | 选择方法 |
|---|---|---|
| 一级：开图地标 | 一处地标展开一整片区域 | 先确定连续旅游组团，再从组团中选一个有代表性、可辨识的建筑、遗产主体或景区入口 |
| 二级：重点游览 | 拍照、首次到访、重访、相册；不授予地图权益 | 很有名，但已位于另一个代表负责的组团内；如明孝陵、总统府、鼓楼、华清宫 |
| 三级：到访记录 | 抵达与日常纪念；不授予地图权益 | 当前保留南京站、西安北站，不将交通枢纽变成开图门槛 |

一级表示**开图职责**，不是全国知名度总榜，也不等同于官方 A 级景区等级。区域代表的全国知名度可能低于二级景点；否则远郊将无法获得合理代表，或被不相邻的城区景点遥控开图。所有等级都可以成为旅行目标、保存照片与接受小队共享。

## 热度依据与取舍

采用公开客流、官方景区名录和旅游片区规划作为**定性热度代理**，没有取得高德／百度逐网格实时热力或全量 OTA 访问数据；不生成虚构的热度分数。资料检索截止 2026-10-02。

- 南京优先参考公安部门发布的 2026 清明热门景区排序，结合官方城南、钟山、玄武湖、江北老山、汤山、牛首及南北郊线路。夫子庙、钟山、玄武湖、牛首山各保留代表；红山因与玄武湖—城北相邻，设为二级。
- 西安参考文物局发布的 2025 国庆中秋客流与 2026 景区名录。兵马俑代表临潼；钟楼代表钟鼓楼—城墙老城；大雁塔代表曲江；大明宫代表北部宫城组团。
- 不将收费景区、开放街区、园区群的原始人次直接相加或比较为精确权重；不同统计范围、季节和假期长度并不相同。远郊代表主要依据官方景区名录与独立地理覆盖，证据强度弱于头部客流组团，应在后续真实到访数据出现后复核。
- 先合并邻近景点，再选代表。秦淮不再拆为夫子庙、门东、中华门；钟山不再拆为中山陵、明孝陵、灵谷寺；西安老城不再拆为钟楼、鼓楼、永宁门；曲江不再拆为大雁塔、芙蓉园、不夜城。

## 覆盖与边界

取得 OpenStreetMap/Nominatim 的南京市 `relation/2131524` 及其 **11 个区**，西安市 `relation/3226004` 及其 **13 个区县**的完整 WGS84 多边形。源几何保留飞地、岛屿、内环和市域外缘，没有用主城包围框代替全市。

市域外缘保持源数据原样，内部以区县为骨架合并。四条组团规划分隔为：玄武区东经 118.812°（城中／钟山）、江宁区东经 118.9°（西南／汤山东）、雨花台区北纬 31.96°（城南／牛首）、西安新城区北纬 34.282°（老城／大明宫）。后两处处理景点跨区现象。这些是**明确标注的规划线**，不能声称是实测道路、河流或官方行政界线；后续可沿实测交通、地形边界校准共享分隔线，但不能破坏全市并集。

拓扑运算验证两城分别满足：`市域 − 分区并集 = 空`、`分区并集 − 市域 = 空`、任意两区的面积交集为空。这里的“完整覆盖”严格对应已下载的 OSM 市域快照；不是对官方测绘界址精度的背书。几何估算南京约 **6,598.7 km²**、西安约 **10,103.9 km²**，不是统计公报面积。西安不因旅游热度把华山或咸阳的景点并入市域，也不将西咸新区的托管口径自动当成行政边界。

市内小区的最小面积为 18.3 km²；郊区最大接近 2,946.1 km²。面积不均等是有意设计：城区有更密集、独立的旅游组团，远郊以较少代表覆盖较大连续范围。展开区域不代表用户已走遍区域；进度按已展开**区域数**统计，不能被解释为实际足迹占地比例。

## 实现与旧数据

- `src/data/map/boundaries/` 保存原始市域／区县 GeoJSON、来源 URL、下载时间和 SHA-256；`src/data/map/city-plans.json` 保存分区几何、代表、等级、面积、依据以及覆盖校验结果。
- `scripts/city-plan.config.mjs` 是可审核的编辑决策；`npm run maps:plan` 离线重建分区，发现遗漏、重叠、代表或景点不在所属区域内会失败。`npm run maps:boundaries -- --refresh` 才重新取行政数据。
- 全市主干道与水域通过 Overpass 一城一份边界框查询获得，WGS84 原始节点随应用打包，详细底图仍为 OSM。缩小到全市时减少低等级道路并聚合邻近开图标记；放大后恢复可见主干道。
- 模型层独立检查 `tier === 1`，二三级 `regionIds` 为空。`regionId` 只说明所属组团；二三级到访即使先发生、即使共享给小队，也不能开图。
- 每条新到访带内容版本。旧记录不补造一次到访，也不把鸡鸣寺、鼓楼等旧小区权益放大成新整区；旧小区原几何仍可见，照片、日期、接收者和回放基线均保留。新分区进度单独统计。
- 入口为“探索 → 全市分区”，可点色块或区域卡片检查负责范围；地标详情显示等级、面积和开图代表。默认列表提供一级开图地标，也可切换全部地标。

## 尚待校准的内容

分区是基于可追溯数据的产品规划，尚未现场勘察。部分坐标来自景点几何中心、入口附近公交站或人工选定的邻近候选点；它们足以表达区域分布，不能冒充已核实的拍照位置。尤其金牛湖、高淳老街、丹凤门、翠华山、太平森林公园及芙蓉园等入口，应在正式设备到访验收前逐一复核。现有 250 米到场半径继续是原型配置。

西安源水域关系 `relation/3895359` 的内环未落入任一外环，导入器记录并跳过该无名水域，不造岸线；市域边界与开图范围不受影响。底图和路网依赖 OSM 完整度，不能保证每条现实道路已被收录。两城全市骨架约 32.5 MB 原始 JSON，按城加载；远端详细瓦片仍不预缓存，慢网与实机性能需要继续验证。
