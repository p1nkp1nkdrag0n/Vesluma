# Pink 本机 SQLite 与同步验收

日期：2026-10-02。基线 `f6c1e8a`，本阶段只在 Pink 追加实现，未合并 main、未部署。后续四城扩展单独提交，不计入本阶段范围。

## 用户可见的结果

“我的足迹”可以主动开启本机数据库同步。到访、开图权益、旅行和照片存入 SQLite；关闭服务再启动保留记录。两个隔离浏览器会话选择同一测试空间可恢复资料，各自离线产生的不同到访合并保留，同一区域不会重复计数。失败有状态提示、立即重试和暂停入口。

旧浏览器记录与照片保持可用。首次启用保存原元数据副本；照片用稳定传输键对应现有本地照片。同步期间继续打卡、接口响应丢失、照片下载失败都保留待同步请求。备份导入先暂停同步，避免迟到响应覆盖新导入内容；恢复时明确说明只增合并。旅行已结束后收到另一会话的离线记录，完整回放仍显示该记录，原结束时间不改动。

## 已覆盖的异常与恢复

1. 同一请求重复和重启重放只保存一次；同请求 ID 不同载荷明确 409，重试不消耗失败的请求 ID。
2. 旧快照、低序号及交错上传做追加合并，不删除新记录；不同到访 ID 保留真正重访，同 user+region 只一份权益。
3. 已结束旅行不因旧快照恢复为进行中；晚到记录仍可见。不可变证据冲突明确失败，不静默选择一边。
4. 照片先于元数据提交；缺图返回 422，上传中断不保存残片；下载失败或本地保存失败不确认队列。
5. 服务断开、响应丢失、刷新与同步中新增打卡仍可恢复；旧 revision 和暂停／导入前发出的迟到响应不回退进度。
6. A/B 资料空间的快照、照片和收据相互隔离；非法城市、引用、位置证据、体积和跨源请求拒绝。
7. 首次同步前保留原始资料；现有照片键、公开开关、定位轨迹和页面偏好按设备保留，新增恢复照片默认私密。

## 明确限制和后续验证

这两个固定空间是测试数据命名空间，**不是账号认证或安全登录**；本机知道空间名的程序能访问数据。SQLite 文件未加密，不面向公开网络。两个浏览器 context 只模拟设备；同一浏览器资料目录多标签页同时写入尚无锁协调验收。

仅同步到访时的位置证据，不同步当前定位或连续轨迹。公开开关仍是本机演示，未实现跨空间公开相册。合并只增加历史，删除／撤回历史、正式小队权限与冲突人工解决界面尚未实现；冲突时应先导出备份，不修改原始证据强行通过。

首次安装 PWA 需加载应用和随包地图。已缓存页面可离线启动，远程详细底图不保证离线可用。全量快照和照片重传适合当前小范围验证，大规模历史、慢磁盘、存储满额及低端真机性能仍需专项测试。临时库测试没有覆盖用户实际设备上的文件权限、杀进程掉电、磁盘损坏或系统备份恢复。
